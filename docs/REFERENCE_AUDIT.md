# Complete reference audit

Checked September 21, 2026.

**31 of 31 works located and checked; no nonexistent or mismatched work found.** Metadata was updated for 17 entries. Nine preprint-only venue fields were replaced with their conference publication details. The other changes complete author lists, volume/issue/pages, or primary links. These updates do not mean that all 17 original citations were false: several were valid but incomplete preprint citations.

The check covers bibliographic identity, authors and order, title, year/version, venue, identifiers, and the claims attached to each citation. Primary metadata and abstracts were read for all entries; relevant full-text passages were checked when needed. It is not an independent proof review of every cited work.

Some publisher redirects and OpenReview pages blocked automated access. Publisher-deposited Crossref metadata resolved the DOI records. Accessible arXiv camera-ready metadata, official conference PDFs, and author/conference pages supported the affected publication checks; details and source URLs are retained in [reference_audit.json](reference_audit.json).

## Citation context checks

- **bengio2009**: Introduces curriculum learning as structured presentation order and reports convergence/generalization benefits. Supports the historical framing.
- **bordelon2022**: Exactly solvable SGD learning curves include Gaussian features, covariance structure, batch size, and finite datasets. Supports the related SGD-moment calculation.
- **bordelon2024**: A random-feature dynamical model links training time, model size, data, and spectral structure to scaling. Supports the spectral-scaling discussion.
- **bordelon2025**: Feature learning can improve scaling exponents for hard tasks; easy-task exponents can remain unchanged. The manuscript makes only the qualified general claim.
- **boucheron2013**: Book on concentration for independent variables, including Gaussian concentration. The cited Gaussian norm tail bound is standard; the manuscript supplies its specialization.
- **chen2023**: Ordered skill dependencies motivate an online mixture-sampling algorithm. Supports the skill-structure and adaptive-mixture descriptions.
- **chen2025**: Aioli estimates mixing-law parameters during training and updates mixture proportions. Supports dynamic data mixing.
- **chen2026**: Olmix studies mixture-method design and reuse when domains are added, removed, partitioned, or revised. Supports the domain-set-change description.
- **dai2026**: The abstract explicitly identifies capacity competition and noise reduction as mechanisms of data-mixing laws. Supports the specific attribution.
- **fan2024**: A proxy model learns domain weights through bilevel optimization before training a larger model. Supports the proxy-optimization description.
- **golden1965**: Original trace-product inequality for Hermitian operators. The manuscript applies the classical two-matrix Golden--Thompson inequality, without claiming a many-factor extension.
- **gu2025**: Language-model data selection is formulated as optimal control with Pontryagin maximum-principle conditions. Supports the control-based data-selection attribution.
- **hacohen2019**: Tests curricula, difficulty measures, and pacing across CNN architectures and datasets, reporting learning-speed and test-performance effects. Supports the empirical context.
- **higham2008**: Covers matrix functions, exponentials, conditioning, and Frechet derivatives. Supports the standard matrix-exponential perturbation tools.
- **hoffmann2022**: Studies compute-optimal allocation between model size and training tokens. The published and preprint titles refer to the same Chinchilla study.
- **kaplan2020**: Empirical loss scaling in model size, data, and compute, with optimal compute allocation. Supports the scaling-law motivation.
- **liberzon2003**: Control-theoretic treatment of switched systems, including arbitrary and constrained switching. Supports the statement that this control setting is established.
- **liu2025**: Fits a regression on small proxy runs to select a static mixture for a larger model. Supports the static-mixture comparison.
- **maloney2022**: A solvable random-feature model relates data/task spectra to power-law loss scaling. Supports the spectral-tail discussion.
- **mori2025**: Combines exact learning dynamics with optimal control for task-selection protocols in continual and multitask learning. Supports the specific protocol attribution.
- **pentina2015**: Studies sequential task transfer and learning the task order using a generalization bound. Supports the distinction between task curricula and fixed-source mixing.
- **saglietti2022**: Teacher-student analysis separates online learning-speed benefits from asymptotic/generalization behavior. Both the proceedings text and later arXiv version support the manuscript sentence.
- **shukor2025**: Predicts loss as a function of model size, token count, and domain weights, then optimizes mixtures. Supports the mixture-scaling attribution.
- **sweeney2026**: The Lie-bracket score predicts the leading local transfer-order effect. The manuscript describes this as local and does not substitute it for a global mixture comparison.
- **thompson1965**: Publisher-deposited abstract explicitly states tr(exp(A+B)) <= tr(exp(A)exp(B)) for Hermitian A and B. Matches the two-phase use in supporting_results.tex.
- **weinshall2018**: Analyzes curriculum difficulty and convergence for convex regression, and transfer-derived curricula for CNNs. Supports the transfer/convergence description.
- **weinshall2020**: Analyzes curriculum learning with convex losses. Supports the convex-loss convergence context.
- **wu2021**: Reports limited benefits in standard regimes and improvements with limited training time or noisy data. Supports the training-regime qualification.
- **xie2023**: Uses proxy-model group DRO to learn weights for larger-model pretraining. Supports the proxy-mixture optimization description.
- **ye2025**: Fits mixture-performance laws and combines them with model/training scaling to predict effective mixtures. Supports the data-mixing-law description.
- **zhao2026**: Transfers dynamic mixtures from proxy loss trajectories, with offline and online variants. Supports the distinction from static RegMix.
